Aucune migration n'est fournie dans cette archive (drizzle-kit n'a pas pu être exécuté hors ligne).
Exécuter `npm run db:generate` pour créer les migrations depuis `src/db/schema.ts`, relire le SQL (voir docs/AUDIT.md §7), tester sur une copie, puis `npm run db:migrate`. Ne pas utiliser `db:push` en production.
